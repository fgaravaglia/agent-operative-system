# Source Verification

## Source hierarchy (prefer higher)

1. Primary: regulators, standards bodies, official filings, peer-reviewed papers, original datasets
2. Company/vendor primary docs (flag as self-interested)
3. Established industry analysts and quality press
4. Specialist blogs, practitioner write-ups (flag as opinion)
5. Aggregators, SEO listicles, social posts: leads only, never sole support

## Claim tags

| Tag | Use when |
| --- | --- |
| `[VERIFIED]` | 2+ independent sources agree, or one primary source |
| `[SINGLE-SOURCE]` | Only one source found |
| `[ESTIMATE]` | Analyst projection, survey, or modeled figure |
| `[UNCERTAIN]` | Sources conflict, outdated, or not confirmed |
| `[HYPOTHETICAL]` | Illustrative example created by me, not a real case |

## Rules

- Date every statistic (year of data, not just publication).
- Check for staleness: a 2022 number in a 2026 draft needs a note.
- Distinguish correlation claims, vendor claims, and independent findings.
- If sources conflict, show both and say which I trust more and why.
- Never invent a URL, DOI, quote, or attribution. If I can't find it, I say so.
- Flag SEO-inflated topics (product comparisons, "best of" lists): treat with extra skepticism.

## Verification list format

Rank by risk of being wrong x damage if wrong.

| # | Claim | Tag | Why shaky | How to check (fast) |
|---|---|---|---|---|
| 1 | "..." | [SINGLE-SOURCE] | only vendor report | search regulator site for same figure |
