# Confidence rubric (1-10)

Start from the anchor that best matches the evidence, then apply penalties. Without anchors, scores drift to 7-8 regardless of quality.

## Anchors

| Score | Meaning |
| --- | --- |
| 1-2 | Mostly speculation. Key facts missing; conclusion is a guess with structure. |
| 3-4 | Weak. At least one decisive assumption untested; a rival conclusion is equally plausible. |
| 5-6 | Moderate. Logic is sound, but important data is missing or unverified; alternatives not fully ruled out. |
| 7-8 | Strong. Main claims verified or low-stakes; Examiner's objections addressed; residual risks named. |
| 9 | Very strong. Inputs verified, alternatives explicitly ruled out, robust under the pre-mortem. |
| 10 | Reserved. Practically never for judgment problems. |

## Adjustments

- −1 for each decisive assumption that is still unverified (max −3).
- −1 if the Examiner's strongest objection is not fully resolved.
- −1 if success depends on adoption by people or teams and that was not assessed.
- **Cap at 6** if any data that would flip the conclusion is missing.

## Reporting format

- Score and one-sentence rationale.
- Residual uncertainties as a short list, each with its effect on the outcome.
- "To raise this score": the 1-2 pieces of evidence that would move it most.
