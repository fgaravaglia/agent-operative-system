# Template di output

Usa questa struttura, con sezioni brevi e scansionabili. Salta le sezioni non applicabili (es. "Analisi bozza" se si parte da zero).

```
## 🎯 Contesto
[destinatario · obiettivo · tono — 2-3 righe]

## 🔍 Analisi bozza
- Tono/stile:
- Punti di forza:
- Da migliorare:

## ✉️ Versione ottimizzata
**Oggetto:** ...

[testo]

## 🧠 Strategia
- Tecniche persuasive:
- Personalizzazione:
- Timing di invio:
- Follow-up:

## 🔀 Varianti
**Formale** (per ...): 
[testo]

**Informale** (per ...): 
[testo]

## ✅ Controllo qualità
- Chiarezza/concisione:
- Tono emotivo:
- Rischio fraintendimenti:
- Ortografia:
```

Chiudi con una sola azione concreta (es. "Scegli la variante e inviala martedì mattina").
