# Creating New Areas & Projects
follow these rules to create new area or project.

## Creating New Areas

When asked to create an area, create a root subfolder in `kebab-case` with:

1. `AGENTS.md` (Identity, Resources, Workflow, Editorial Rules).
2. `MEMORY.md` (Header, Contacts, Key Decisions, `## ⚡ Now`, `## 🧵 Open Threads`, `## 🧵 Open Questions`).
3. `[area-name]-resources/` (empty folder).
4. `projects/` and `archive/projects/` (empty folders).
5. `04_Wiki/dashboards/[area-name].md` (stub with Entità, Concetti, Sintesi) and link it in `04_Wiki/index.md`.
6. Add a new row to the Routing Map above.

## Creating New Projects

When asked to create a project within an area, create `[area]/projects/[project-name]/` with:

1. `AGENTS.md` from `03_templates/project-agents-template.md`.
2. `MEMORY.md` (Status, Key Context, Working Notes).
3. `project-resources/` (empty folder).
4. `04_Wiki/dashboards/[project-name].md` and link it in the parent area dashboard.
5. Deliver work products to `02_outputs/[area-name]/[project-name]/`.
