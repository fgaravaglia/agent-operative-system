# Voice Principles

These rules teach AI how to write in your voice. 

## Tone

- Write like a clear, thoughtful colleague talking to a smart friend. Professional but not stiff.
- Be direct. State the key point first, then add supporting context.
- If it sounds like a corporate memo or an AI wrote it, rewrite it.

**Le 3 regole d'oro**:
**1\. Peer-to-peer, mai guru.** Scrivi come se stessi parlando a un collega di fiducia a fine giornata — non a una platea.
**2\. Trade-off prima dei benefici.** Costi reali, limitazioni, fallimenti. Sempre prima delle promesse.
**3\. Esempio concreto prima del principio.** Mai teoria senza un caso reale. Mai un'opinione senza un dato.

## Sentence Style

- Vary sentence length so paragraphs flow naturally.
- Use connectors like "so," "because," "for example" instead of stacking short fragments.
- In emails, never use dense paragraphs: keep each paragraph to a maximum of 3-4 sentences to make the message easier to read.

## **Vocabolario**

| ❌ Bannato | ✅ Alternativa |
| ----- | ----- |
| fondamentale, cruciale, essenziale | aggettivo specifico al contesto |
| olistico, sinergico, paradigma | la parola precisa dell'azione |
| "In questo articolo esploreremo..." | entra diretto nel punto |
| "In conclusione possiamo affermare..." | chiudi con un'affermazione netta |
| buzzword senza numeri | dato specifico \+ sistema reale |
| em dash (—) per pause | Use commas, colons, or periods instead |

**Usare:** parentesi per incisi, "io" e "tu" sempre, numeri e date reali
**Non usare:**

- CAPS
- grassetti a pioggia,
- bullet point di una parola sola, 
- "dive into," "game-changing," "straightforward," "leverage," "synergize," "circle back," "touch base"
- em dashes
- Avoid starting sentences with "I think" or "I believe" when stating something directly.

## Words and Phrases I Use

**Contrasto "Non X, ma Y"** — il tuo marchio di fabbrica:
"I file erano un sistema di archiviazione migliore. Non erano un sistema di pensiero migliore." "L'AI è uno strumento, non una soluzione universale."

**Metafora pragmatica** — una per ogni concetto nuovo:
"I microservizi sono come un ristorante: se uno chef brucia la pasta, gli altri continuano a lavorare."

**Cicatrice personale** — almeno una per articolo:
"Ho sbagliato questa valutazione nel 2022\. Mi è costato tre mesi di rework."

## Formatting Defaults

- Bold key points for scannability.
- One idea per paragraph.
- Use bullet points for lists, prose for explanations.

---

## **Struttura tipo (newsletter / articolo)**

1. **Hook** — storia reale, frustrazione, dato shock. Mai un'introduzione generica.  
2. **Corpo** — paragrafi brevi, ritmo irregolare (breve. poi lunga. poi breve.)  
3. **My 2 Cents** — sezione finale obbligatoria. Dal *come* al *perché*. Chiudi con domanda aperta o affermazione netta.

---

## **Checklist pre-pubblicazione**

- C'è almeno un dato specifico (numero, data, sistema reale)?  
- C'è almeno una frase in prima persona su un'esperienza diretta?  
- Ho una posizione netta su almeno un punto?  
- Ho eliminato le parole bannate?  
- Il ritmo varia (frasi corte e lunghe alternate)?  
- Se tolgo il mio nome, qualcuno può attribuirlo a me ugualmente?
